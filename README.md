## 📱 2. APP VERSION (Installable Mobile & Desktop App)

The application is built as an **Installable Progressive Web App (PWA)** that runs standalone on **Android, iOS (iPhone/iPad), Windows, and macOS** with an offline Service Worker and high-quality RS-25G App Icon.

### 📱 Installing the App on Android & Mobile:
1. Open the website link in **Chrome** or **Edge** on your phone.
2. Tap the **`📱 Install App`** button in the header bar OR tap the browser menu (`⋮`) ➔ select **"Install app"** or **"Add to Home screen"**.
3. The **RS-25G Relentless Growth App** icon will appear directly on your phone's home screen & app drawer!

### 🍎 Installing the App on iPhone / iPad (iOS):
1. Open the website link in **Safari**.
2. Tap the **Share** button (`[↑]`) at the bottom of the screen.
3. Scroll down and tap **"Add to Home Screen"**.

### 💻 Installing the App on Windows / Mac (Desktop):
1. Open the website link in **Chrome** or **Edge**.
2. Click the **`📱 Install App`** button in the top navigation header OR click the **Install icon (📥)** in the browser address bar.
3. The app will install as a standalone desktop application window with its own taskbar shortcut!
